# Nala vs. los Bots 🦦

Juego de **STEAM Girls** (@steamgirlsclub) creado para el stand de Campus Party Buenos Aires 2026.
Nala defiende el stand de un ejército de IAs descontroladas usando **código, conocimiento y criterio**.

## Cómo se juega
- **↑ ↓** o clic en un carril: mover a Nala (el código se dispara solo)
- **2** Conocimiento: rompe la máscara de los deepfakes
- **3** Criterio: frena a las alucinaciones
- Atrapá la **W de WHAT I DO** para llamar a la comunidad

## Archivos
- `index.html`: el juego completo (imágenes, fuentes y sonido incluidos)
- `og.jpg`: imagen para cuando se comparte el link
- `supabase.sql`: crea la base de datos del ranking y el contador de visitas

Hecho con HTML, CSS y JavaScript (Canvas 2D y Web Audio), con ayuda de IA.
